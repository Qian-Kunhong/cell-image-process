# YAP 核/核周比 v3：按 DAPI 排除全部核，保留少量像素

## 当前规则（优先于本文后面的历史 v2 记录）

按用户明确要求，不安排人工验证；取消按面积比例、角度覆盖、信号支持率进行硬排除。默认只要有 **1 个**采样像素即记录强度。

1. 使用完整原始 DAPI 核标签图，包含未进入形态学模型的核。
2. 每个核向外扩张至 `max(2, round(.20D))` 像素（D 为该图核等效直径中位数）；按最近核边界分配唯一标签。同一像素不会同时属于两个核周区。
3. 排除 **全部** DAPI 核像素，不增加原 v2 的 `.08D` 核外缓冲带。取样区域中核像素数必须严格为 0，并写入运行核验信息。
4. 在对应灰度 YAP 通道测量核/核外区域的所有像素；不按 YAP 亮度选取或删除像素。核与核外的均值、中位数均保留，主比值仍使用中位数。
5. 取样面积小、角度不完整、低信噪比、靠近图边、导出上限裁切均只记录 `posthoc_yap_qc_warnings`，不再屏蔽已定义的比值。

### 三种状态分开，不再统称“QC 通过”

| 状态/字段 | 含义 |
|---|---|
| `posthoc_yap_sampling_valid` | 默认至少 1 个非核取样像素；与有无背景无关 |
| `posthoc_yap_raw_ratio_valid` | 未校正比值 `median(N)/median(R)` 为有限正值 |
| `posthoc_yap_ratio_valid` | 校正比值 `(median(N)-B)/(median(R)-B)` 为有限正值；**不表示质量经过验证** |

`posthoc_yap_raw_nuclear_perinuclear_ratio` 和 `posthoc_yap_raw_log2_nuclear_perinuclear_ratio` 是未扣背景值；单独输出到 `yap_ratio_raw_uncorrected` 图目录，不与原校正比值列或校正统计混用。背景不足时，原始强度和未校正比值仍保留；校正列为 NaN。背景仍采用原自动远核区域中位数，没有添加未经校准的背景回退。正但很小的分母会得到实际比值并提示低信噪比，不加 epsilon、不裁剪表中数值；分母非正时不输出校正比值。

面积小不等于无效，但测量可能更不稳定；分割误差、离焦或胞质混杂并未被修复。此方法仅保证**相对现有分割掩膜**不包含自己的核或邻核，不保证识别未分割核，也不保证核外像素属于该细胞而非邻细胞胞质。仍是核/核周代理，不是完整细胞核质比或多能性标签。

`posthoc_yap_qc_reasons` 现在仅记录比值数学上/背景上不可用的原因。旧 `ring_coverage_pass`、`strict_gate_pass_diagnostic_only`、SNR 2/3/5 敏感性标志仅供历史规则诊断，不参与筛选。为兼容旧读取程序，汇总表保留 `n_ratio_technical_qc_pass` 名称，其值等同于明确命名的 `n_corrected_ratio_available`，不可再解释为严格质量通过。

重测默认写入新的 `yap_dapi_excluded_v3_<时间戳>` 文件夹；不改旧输出，不重跑 DAPI 分割、特征、UMAP、GMM，所有细胞行和后验概率保持不变。测试增加：单像素区域保留、提高邻核 YAP 强度不改变本核的核周测量、所有采样像素核重叠为 0、调整警告阈值不改变可用比值。

## 历史 v2 方法记录（已停用其硬门槛）

以下内容记录上次实现及其研究背景，**不是当前默认算法**。v2 的面积/角度等阈值未经验证，不再作为硬筛选；保留文字便于解释旧 `yap_qc_v2_*` 输出。

## 研究中常见做法

1. DAPI 定义核、另有细胞体/膜标记定义整细胞，胞质 = 整细胞减核；分别统计强度并计算 N/C。STAR Protocols 的 YAP/TAZ 高内涵流程采用核区与胞质区的**中位数**，说明中位数本身并不是旧算法的问题。[原始流程](https://pmc.ncbi.nlm.nih.gov/articles/PMC8254078/)
2. 可见细胞边界时，人工在核、胞质、细胞外背景画 ROI；扣背景后计算比值。[YAP1 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6035388/)
3. 密集细胞也有使用核周窄环的研究。Franklin 等在特定活细胞成像条件下采用核外 0.5 μm 区域及扣背景的平均强度，不能把该物理宽度直接套到没有像素标定的 PNG 上。[Nature Communications 2020](https://www.nature.com/articles/s41467-020-18368-x)

有独立胞质/膜染色时可用细胞体前景约束核扩张；CellProfiler 明确区分不看图像的 Distance-N 与使用前景阈值的 Distance-B。[官方文档](https://cellprofiler-manual.s3.amazonaws.com/CPmanual/IdentifySecondaryObjects.html)

当前数据仅 DAPI + AF488/YAP，没有独立胞质/膜标记。v2 仍然是 **nuclear/perinuclear enrichment proxy**，不是确认的完整细胞核质比。YAP 核富集也不等于已经证明转录活性或多能性。

## 计算与参数

所有强度来自灰度 `AF488_ORG`，不使用显示拉伸、Merge RGB 或伪彩色数值。核保持现有完整 DAPI 分割，不额外按 YAP 选择核像素或去核仁。每个细胞保存核/核周环**中位数和均值**；主结果保持中位数口径：

`ratio = (median(N) - B) / (median(R) - B)`，绘图为 `log2(ratio)`。

下列数值是可审查的工程初始参数，不是论文公认标准、阳性阈值或通过实验验证的切点。`--yap-qc-config` 可传 JSON 覆盖，具体值写入输出。

| 项目 | 默认规则 |
|---|---|
| 核周环 | 按整图核等效直径中位数 D，内间隔 `max(1, round(.08D))`，外距离 `max(内间隔+2, round(.20D))` px |
| 避免邻核 | 扩张全部原始核标签；环不重叠、不包含任何核（包括 DAPI QC 排除的核） |
| 背景候选 | 距全部分割核 > `round(1.5D)`；至少 `max(100, ceil(.005×图像像素数))`；或同图人工无细胞 ROI |
| 背景 B / 噪声尺度 s | 候选区中位数 / `max(1 DN, 1.4826×MAD)`；1 DN 是 8-bit 输出量化的保守下限，非实测相机读出噪声 |
| 检出门槛 | 核、环扣背景中位数均 > `3s`；低分母不补 epsilon，不输出无穷大 |
| 环面积 | ≥20 px 且 ≥核面积的20%，由提示项升级为通过条件 |
| 信号支持率 | 整环 ≥70% 像素 > `B+3s` |
| 角度覆盖 | 围绕核质心分8扇区，至少6区有≥3像素且其中≥50%高于 `B+3s` |
| 图像边界 | 核 bbox 到边界距离 ≤外环扩张距离时拒绝（保守条件） |
| 导出裁切 | 核或环中 ≥255 DN 像素比例 >1% 时拒绝；这是导出上限裁切指标，不等同于诊断相机饱和 |

**强度统计仍使用完整几何环的所有像素**。信号/角度规则只决定该细胞的 ratio 是否可报告，不把暗像素删除后再计算“修正比值”。只有几何环变窄会改变取样，QC 本身不会改变通过细胞的强度数值。

背景候选不是经过独立染色确认的空白区，可能有未分割细胞/突起。必须检查 `ring_qc` 中的黄色边界。没有足够候选背景时，新主比值为 NaN，不能用整图最低分位强行代替。人工 ROI 可以解决同图确有空白但几何规则找不到的情况；如果全图确无空白，应重新采集匹配背景/原始图像，不借用另一个组的背景。

## 输出、审计与限制

- `posthoc_yap_*_median_raw`、`*_mean_raw`：所有核/环原始强度，未通过 QC 也保留。
- `posthoc_yap_nuclear_perinuclear_ratio` / `log2_*`：**通过技术 QC** 的主结果；不可测为 NaN，绝不记为0或低YAP。
- `posthoc_yap_mean_nuclear_perinuclear_ratio`：同 ROI、同技术 QC 下的均值比。用于检验均值/中位数选择敏感性。
- `posthoc_yap_unfiltered_narrow_ratio`、`unfiltered_wide_ratio`：未过 QC 的窄/宽环比，**仅审计，不进入主汇总**；宽环外距离 .35D。
- `posthoc_yap_legacy_v1_ratio`：精确复现旧 .35D 环与旧背景回退，仅供历史对照；不能混入新结果。
- `posthoc_yap_qc_reasons`：所有未通过原因；同细胞可有多项，原因计数不可直接相加当人数。
- `posthoc_yap_nuclear_detected_ring_unresolved`：核可检出、环不可可靠检出，不是阳性/阴性或激活分类。
- `posthoc_yap_sensitivity_snr_2/3/5_pass`：SNR 门槛改变时通过状态；背景±1噪声尺度的比值为敏感性诊断，**不是置信区间**。
- 每视野、每形态表型报告可测比例，分组比较仅对可测子集描述，不把单细胞当生物学重复。

此 QC 会更常排除胞质弱、稀疏、边缘或高密度环受挤压的细胞，其中也可能包括真实核富集细胞。因此**不能将筛选后边缘不红理解为伪影已经纠正，或用“更好看”验证算法**。新版只把无法可靠区分背景污染与真实弱胞质信号的情况暴露出来。即使通过 QC，仍可能有邻细胞胞质污染；角度信号覆盖不是细胞边界真值。宽/窄环比较应查看同细胞结果，不只比较两个筛选集合的总体均值。

真正要验证核质定位，优先补充独立胞质/膜标记或经人工核验的细胞范围，并保存线性未拉伸的显微镜原始数据、曝光与像素标定。当前算法不做未校准的跨图曝光、空间亮度或细胞周期校正。HA1/HA2 同时改变时间与剂量的混杂不由此算法消除。

## 不改变形态学模型

YAP 代码只在模型完成后调用。`refresh_yap_posthoc.py` 不分割、不做预处理、不拟合 GMM/UMAP；只合并新的 `posthoc_yap_` 列。全部 DAPI 特征、细胞行、元数据、主导表型和每一个后验概率保持不变。旧输出和 mask 通过 SHA256 检查，新结果写入全新目录。

测试：`python -m unittest discover -s Ekin_DAPI_YAP -p "test_*.py" -v`（项目根目录执行）。包括已知比值、真实高比值、半环空白、近零/负分母、缺背景、手工 ROI、图像边缘、裁切、邻核隔离及模型后验不变。
