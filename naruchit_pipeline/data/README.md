# data/

**这个目录里不存数据，只存“数据在哪、能不能用”的说明。**

原始数据一律留在外部盘（本项目为 `F:\...`），原因有三条：

1. 图像/流式原始文件动辄几十 GB 到若干 TB，进 git 会把仓库撑死；
2. 原始数据要求只读，混进工作目录后很容易被脚本顺手改写；
3. 换机器时只需要改 `config/project.json` 里的 `data_root`，代码不用动。

## 数据资产登记

| 名称 | 路径（相对 data_root） | 单位 | 实有数量 | 用途 | 硬限制 |
|---|---|---:|---|---|---|
|  |  |  |  |  |  |

填表规则：

- **单位**写清楚是“孔 / 视野 / 图像 / 细胞”，这一列决定后面能不能做统计。
- **硬限制**必须写，例如“每条件仅 1 视野”“与标签无共同键”。不写的话，三个月后一定会有人把它当独立重复用。
- 每次新增数据集就追加一行，不要改历史行。

## 与代码的关系

代码所有数据读取都经过 `src/rp/paths.py` 的 `data_path()`，禁止在脚本里硬写 `F:\...` 绝对路径。
这样数据盘换位置时只改一个 JSON。
