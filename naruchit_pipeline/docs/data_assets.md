**结论**：



1. **掩膜与逐核表完全自洽（10/10 一致，973 = 973）**，二者是同一版本，可作为当前细胞级事实来源。

2. **`condition_3d_summary.csv` 的 `n_nuclei` 与掩膜不同步**：6 个样本对不上，合计多 18 个核。但两套的核体积中位数在 7 个样本上逐位相同（D20D 1380.7892875271、D40D 561.1032792398、D33D 984.8081715769），说明**核集合高度重叠，差异来自计数规则（哪些核算 “有效”），不是重新分割过**。

3. 因此 “991” 和 “973” 是**两个计数口径**，不能互相替代：引用 991 必须注明来自旧汇总表、且未逐核对齐；本项目统一用 **973**（掩膜口径）。

4. 由于核集合基本重叠，旧汇总里的体积中位数等统计量**仍可作为参考**，但凡是写进正文的数字，都应以本项目重算的 `population_features.csv` 为准，避免同一张表里两种口径混用。

### 2 条件代码解码（有证据，不是推测）

**由此确定一件事**：这 20 个共聚焦 OIB 与 2821 核的 YAP 定量属于**扩增期**（5 天维持培养的最后三天），不是分化期。论文 Fig.1A/Fig.3 讲的也是这一段。分化期（4 剂量 0/1/5/10 nM）的图像在 `incell_if`、`biostudio_differentiation_timelapse`。

### 5 待确认（未证实，不许当结论写）



1. **2D 切片与 3D 栈的关系**：`yap_quantification` 的切片是 800×800，每条件 3–11 张（`01-C1/01-C2 …` 双通道成对），与同条件 OIB 同名。是否为同一采集栈的不同 z 层，尚未验证（`.oib` 不是标准 TIFF，头部无法直接读尺寸）。若同栈，2821 是 “切片上的核计数”，不是细胞数。

结论三条：



1. **有**：按 “剂量 + 时间点” 对齐的早期与后期数据，共三条线 ——IN Cell（D0/D3 ↔ D17/D21，4 剂量）、RT-PCR（D3 ↔ D17/D21，4 剂量带 3 复孔）、明场时程（同孔连续，D3→D21，4 剂量）。

3. 唯一真正 “同一个孔从早期拍到最后” 的是明场时程，但它没有核染色，只能给群体形态，不能给核表型。
