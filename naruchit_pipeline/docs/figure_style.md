# 图形规范（复刻 Ekin 版式时必须遵守）

> 引入原因：2026-11-06 一夜之间森林图出了 6 版（06c–06h）、YAP 箱线图 4 版（07b–07d）、分割演示图 4 版（08b/08c/09/10/11），其中 5 次是"改错图"。本文件把已确认的版式参数写死，新图直接照抄，不再逐版试。

## 0 动笔前必须先回指

- 改图前先写一句"你要改的是〔图名〕的〔哪个问题〕"，得到确认再动代码。
- 用户贴出另一张图当参照时，先判断它是"参照"还是"目标"：参照图只提供风格，不改它本身。

## 1 日期配色（全项目统一）

| 时间点 | 色值 | 用途 |
|---|---|---|
| Day −2 | `#2166AC` 蓝 | 散点、箱体填充、图例 |
| Day −1 | `#4DAF4A` 绿 | 同上 |
| Day 0 | `#E8985E` 橙 | 同上 |

- 三个色值在森林图与箱线图之间必须一致；不要一张图蓝绿橙、另一张换色系。
- 面板/组别只用灰（`#888888` / `#AAAAAA`），不抢日期颜色。

## 2 森林图（HA effect）

- 效应量：`effect = (median(HA) − median(no-HA)) / IQR(no-HA)`，单位写 `Effect size (IQR units)`，0 处画灰色虚线。
- 纵向每行一个特征（Nuclear area / Elongation / Circularity / Nuclear spacing / Local crowding / Neighbor heterogeneity）。
- 面板两栏：Single HA、Repeated HA。
- 每个特征 × 每个时间点 = **一个点**，按日期上色；同一行的三个点纵向错开（±0.1）。
- 连线的语义必须在图例或图注写清：当前 v10 的横线是**三个时间点的 min–max**，不是 95% bootstrap CI。若改回 CI 必须写明"95% bootstrap CI"，不能含糊。
- **不再叠加跨时间点菱形**：菱形会压住点，且与"每时间点各取中位数"的口径冲突。
- 尺寸 `figsize=(13, 5)`，`dpi=220`，`bbox_inches="tight"`；x 轴标签与图权重叠即视为不合格。

## 3 箱线图（YAP / 形态按日期）

- 数据源必须是 3D 共聚焦 **QC 通过**的核：`df[df["qc_pass_uniform"] == True]`，不许直接用全检测（那会得到 1573 而不是有效核）。
- 日期分组用第 1 节三色；可加日期背景色带，但色带不得与箱体同色。
- 中位数用箱内横线表达，不再额外叠菱形。
- 图上元素以"看得清"为准：不过度装饰，不加跨组汇总标记。

## 4 分割演示图

- 必须先找既有实现：3D 用旧仓 `segment_dapi_3d_pilot.py`；2D 用既有 cellpose 模型与既有 2D 流程（不要自己硬阈值分割）。
- overlay 用 RGBA 数组只在轮廓像素上色；不要用 `cmap="Reds"` 之类把 0 值映射成白色洗掉背景。
- 面板数与排列按用户给的参照图（三面板：原图 / 轮廓 / 掩膜着色），不自行加面板。

## 5 图注与标题

- 图注 **≤2 行、一句话**：说清"画的是什么数据、每组 n、点和线的含义"。PPT 用的图注不许超过两行。
- 标题用陈述句，不用问句；标题里带的核数必须与 `docs/counting_ledger.md` 一致（如 "868 matched nuclei"）。
- 图内文字字号 ≥10；图内不写方法学解释。

## 6 落盘

- 输出到 `analysis_outputs\<编号_主题>\`，文件名带版本号（`_v10`），旧版本保留不删——需要对比时直接引用。
- 同一主题的脚本只保留一个"当前版"，其余在文件头标注 `deprecated: 被 xx 取代`。
