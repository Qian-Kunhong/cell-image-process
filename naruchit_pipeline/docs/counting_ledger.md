## 2 使用规则

- **1573 / 973 / 991 是同一批 3D 视野的三种"数核方式"，只能选一个用**：正文一律 973；991 只能出现在"旧口径、已弃用"的说明里；1573 只用于说明分割前后差多少，不当作核数。
- **2821 不是细胞数**：它是 2D 切片上的核计数，同一条 z 栈的多个切片会重复计同一个细胞。凡是写"2821 个细胞"都是错的，只能写"2821 个核检测（2D 切片）"。
- **868 只能叫"匹配核"**，不能简称"核数"，因为它只是 973 与 2D 检测的交集。
- **1190 / 1182 是"最佳焦平面 2D 掩膜"的核数**，既不是 2821（CellProfiler 全切片检测），也不是 973（3D 有效核）；图里用它时只能写 1182（9 样本），不能写成 2821 或 973。
- 六个数**不得相加、不得换算**。
- 写进文档前先在本文档检索该数字；本表没有的数一律不许出现在正文、图注、PPT 里。
- 新增口径时先加本表一行 + 更新 `verify_count_ledger.py` 的期望值，再使用。
